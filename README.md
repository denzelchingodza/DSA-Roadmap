# DSA Roadmap

Personal data structures & algorithms study repo, built around the NeetCode roadmap / Blind 75 problem set, working toward junior developer interviews in Python.

## How this repo is organized

Each topic below has its own folder with a `README.md` (concept write-up: what it is, where it's used, complexity, core algorithms/patterns, mapped Blind 75 problems) and a `problems/` folder for solved NeetCode problems as individual `.py` files once I move into the solving phase.

## Study approach

**Phase 1 — Understand (current phase, ~2 weeks).** Go topic by topic in the order above. For each: what the structure is, where it shows up in the real world, its time/space complexity, and the core algorithms/patterns tied to it — each pattern walked through as pseudocode, then a brute-force solution, then the optimized solution, with an explanation of *why* the optimized version works and what conceptual leap gets you there.

**Phase 2 — Solve.** Once a topic is understood, work through its mapped Blind 75 problems in `problems/`, starting from the pattern learned in Phase 1.
