# DSA Roadmap
This repo is where I'm documenting my journey learning Data Structures & Algorithms, working through the [NeetCode roadmap](https://neetcode.io/roadmap), with the goal of being able to confidently solve interview style problems (NeetCode Blind 75 / NeetCode 150) by the end.

## What this is

Not just solved problems for each topic, I want to actually understand:
- what the data structure is and how it works under the hood
- what operations you can do on it, and their time/space cost
- which algorithms/techniques get applied to it, and when to reach for each one
- the math underneath why these techniques actually work

## Roadmap

Following the NeetCode order: Arrays & Hashing, Two Pointers, Sliding Window, Stack, Binary Search, Linked List, Trees, Tries, Heap/Priority Queue, Backtracking, Graphs, Advanced Graphs, 1-D DP, Intervals, Greedy, 2-D DP, Bit Manipulation, Math & Geometry.
