# DSA Roadmap

This repo is where I'm documenting my journey learning Data Structures & Algorithms, working through the [NeetCode roadmap](https://neetcode.io/roadmap), with the goal of being able to confidently solve interview style problems (NeetCode Blind 75 / NeetCode 150) by the end.

## What this is

Not just solved problems for each topic, I want to actually understand:
- what the data structure is and how it works under the hood
- what operations you can do on it, and their time/space cost
- which algorithms/techniques get applied to it, and when to reach for each one
- the math underneath why these techniques actually work.

## How this repo is organized

Each topic below has its own folder with a `README.md` (concept write-up: what it is, where it's used, complexity, core algorithms/patterns, mapped Blind 75 problems) and a `problems/` folder for solved NeetCode problems as individual `.py` files.

## Study approach

**Phase 1 — Understand.** Go topic by topic in the order above: what the structure is, where it shows up in the real world, its time/space complexity, and the core algorithms/patterns tied to it — each walked through as pseudocode, then brute force, then optimized, with the reasoning for why the optimized version works.

**Phase 2 — Solve.** Once a topic is understood, work through its mapped Blind 75 problems in `problems/`.

Advanced Graphs, both DP sections, Intervals, Greedy, Bit Manipulation, and Math/Geometry get picked up once problem-solving is underway in week 3+, rather than crammed into the early understanding phase.
